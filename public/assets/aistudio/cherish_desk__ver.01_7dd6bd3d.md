# 🍒 CHERISH DESK — 나만의 미니멀 데스크 전공 공부 & 수집 아카이브

> **"좋아하는 것들을 소중히 모은다(Cherish)"**
>
> 컴퓨터교육 & 디자인을 함께 전공하는 여대생의 아늑한 화이트 데스크를 모티브로 한 **포인트 앤 클릭(플래시 게임 스타일) 인터랙티브 개인 공부 노트 & 취향 수집 웹사이트**

---

## 1. 프로젝트 개요 및 페르소나 (Concept & Persona)

### 1.1 사용자 페르소나 (User Persona)
* **전공 배경:** 컴퓨터교육과(주전공) + 디자인(복수/부전공)
* **취향 및 감성:** 깔끔한 미니멀 화이트 & 큰 노란색 체크무늬(버터 옐로우 체크)의 산뜻하고 귀여운 분위기를 좋아하며, 아기자기한 문구류·소품과 "모으는 재미"에 애정을 느끼는 대학생
* **사용 목적:** 딱딱한 일반 필기 앱 대신, 내 책상 앞에 앉아 소품을 클릭하듯 **교육학(정보교육론·교수법)과 컴퓨터공학(자료구조·알고리즘·코드), 디자인 영감**을 한 권의 책처럼 소중히 수집(Cherish)하고 모으는 나만의 공간

### 1.2 핵심 컨셉 키워드
1. **Cherish (수집과 애정 — "좋아하는 걸 모은다"):**
   * 전공 개념, 수업 아이디어, 아름다운 코드 스니펫, 디자인 레퍼런스 등 **내가 좋아하는 것들을 하나씩 수집**
   * 유독 아끼는 항목에는 **체리(🍒)**를 달아 **체리 컬렉션(수집함)**에 차곡차곡 모으고, 모은 개수에 따라 수집 배지·체리 바구니가 채워지는 재미
2. **Big Yellow Checkered Entry (진입 시 큰 노란색 체크무늬):**
   * 페이지에 처음 들어왔을 때 **크고 선명한 노란색 체크무늬(Big Yellow Checkered Pattern)**가 화면 배경이나 웰컴 프레임으로 펼쳐지며 산뜻하고 귀여운 첫인상을 연출
3. **Minimal White & Cozy Desk:**
   * 퓨어 화이트 책상과 타공판, 버터 옐로우·크림 톤의 소품이 어우러진 미니멀 & 러블리 무드
4. **Point & Click (플래시 게임 UI):**
   * 화면 전환을 최소화하고, 책상 위 실제 사물(책꽂이, 아이맥, 타공판, 연필, 시계, 스피커, 체리 바구니 등)을 마우스로 클릭해 상호작용
5. **Standard Web Structure:**
   * 감성적인 1인칭 책상 화면 위아래로 정석적인 `<header>`와 `<footer>`를 배치하여 웹 표준과 탐색 편의성 확보

## 2. 웹사이트 레이아웃 설계표 (Information Architecture)

| 영역 구분 | 세부 구역 | 배치 위치 | 핵심 역할 및 인터랙션 방식 | 메모 / 커스텀 작성란 |
| :--- | :--- | :--- | :--- | :--- |
| **Entry / Backdrop** | **큰 노란색 체크무늬** | 페이지 진입 시 전체/배경 프레임 | 페이지 접속 시 **큰 노란색 체크무늬**로 반겨주며, 책상 스테이지로 자연스럽게 연결되거나 배경 체크 무드로 유지 | |
| **Header** (`<header>`) | 상단 내비게이션 바 | 화면 최상단 고정 | 로고(`CHERISH DESK`), 전공 과목 필터(`전체`, `교육학`, `컴퓨터`, `디자인`), **체리 수집함(🍒)**, 게시판 전체보기 토글 | |
| **Main Stage** (`<main>`) | **정면 벽면 (화이트 타공판)** | 화면 상단 좌·중앙 | 타공판(페그보드) 형태의 메모 보드. 오늘의 목표, **수집한 체리(🍒) 카드/포스트잇** 부착 | |
| **Main Stage** (`<main>`) | **중앙 iMac 모니터** | 책상 중앙 정면 | 평소엔 큰 노란 체크/미니멀 웰컴 화면, 책을 클릭하면 **양면 노트(좌: 개념·수집 메모, 우: 코드·실습)** 출력 | |
| **Main Stage** (`<main>`) | **우측 책꽂이 (게시판)** | 책상 위 오른쪽 | **교육 과목**, **컴퓨터 과목**, **디자인** 전공 책들이 꽂혀 있는 게시판. 호버 시 돌출, 클릭 시 아이맥/책상에서 열림 | |
| **Main Stage** (`<main>`) | **책상 위 귀여운 소품들** | 책상 상판 좌·우·중앙 | 펜꽂이(새 노트 수집/작성), **체리 수집 바구니/트레이**(모은 것 모아보기), 아날로그 시계(타이머), 크림 스피커(BGM), 버섯 스탠드(조명 전환) | |
| **Footer** (`<footer>`) | 하단 푸터 | 화면 최하단 고정 | 프로젝트 한 줄 소개, 수집 현황 요약, 과목/목차 링크, 저작권 표기 (`© 2026 CHERISH DESK`) | |

## 3. 디자인 시스템 정의표 (Design System)

| 카테고리 | 항목 | 정의된 스타일 가이드 (Big Yellow Check × Clean White) | 메모 / 커스텀 작성란 |
| :--- | :--- | :--- | :--- |
| **Pattern** | **진입 큰 노란 체크무늬** | 큼직한 격자 크기의 **버터/레몬 옐로우 체크무늬** (예: `#FFF3B0` / `#FDE047` + 화이트 `#FFFDF7` 격자) | |
| **Color** | 메인 배경 (벽면 / 책상) | 웜 화이트 `#FAF9F6`, 퓨어 화이트 `#FFFFFF` | |
| **Color** | 보더 & 입체 그림자 | 소프트 그레이 `#E5E7EB`, 은은한 책상 오브젝트 그림자 `rgba(30, 41, 59, 0.06)` | |
| **Color** | 기본 텍스트 | 딥 차콜 `#1E293B` (본문), 슬레이트 그레이 `#64748B` (보조 설명/손글씨 라벨) | |
| **Color** | 핵심 포인트 (Cherish 🍒) | 체리 레드 `#E11D48` (수집 체리 아이콘, 책등 포인트 라벨, 강조 태그) | |
| **Color** | 서브 파스텔 (소품/책등) | 버터 옐로우 `#F6E08B`, 베이지 크림 `#EAE4D7`, 파스텔 핑크 `#F7C5CC`, 세이지 민트 `#CFE6D9` | |
| **Typography** | UI / 제목 폰트 | 깔끔하고 현대적인 산세리프 (`Pretendard`, `Inter`) | |
| **Typography** | 소품 가이드 라벨 | 사진 속 화살표 안내 느낌을 살린 귀여운 손글씨 폰트 (호버 시 `↘ 새 글쓰기` 등 표시) | |
| **Typography** | 코드 / CS 개념 폰트 | 가독성 좋은 고정폭 폰트 (`JetBrains Mono`, `D2Coding`) | |
| **Shape & Motion** | 모서리 & 애니메이션 | 둥글고 부드러운 라운드(`12px~16px`), 호버 시 사물이 살짝 떠오르는 인터랙션(`0.25s ease`) | |

## 5. 전공 과목별 책꽂이 분류 예시 (Content Structure)

* **📕 [교육 과목] 정보교육론 & 교수법**
  * 예: *파퍼트(Papert)의 구성주의와 블록 코딩 교육*, *컴퓨팅 사고력(CT) 평가 루브릭 설계*, *언플러그드 활동 수업 지도안*
* **📘 [컴퓨터 과목] 자료구조 & 알고리즘 & CS**
  * 예: *스택(Stack)과 재귀 호출의 연결*, *이진 탐색(Binary Search)의 효율성*, *버블 정렬 시각화 원리*
* **📒 [디자인 & 융합] UI/UX & 인터랙티브 미디어**
  * 예: *미니멀 화이트 컬러 시스템과 여백의 미*, *교육용 웹 인터페이스의 어포던스(Affordance)*
